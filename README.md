# Regex Data Extraction & Validation

## Overview
This tool extracts emails, URLs, phone numbers, and credit card numbers from raw text, with special validation for ALU email domains. It also rejects malicious input.

## ALU Email Validation
- `@alueducation.com` (official)
- `@alumni.alueducation.com` (alumni)
- `@si.alueducation.com` (SI)
